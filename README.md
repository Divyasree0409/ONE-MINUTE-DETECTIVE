# ONE-MINUTE-DETECTIVE
Abstract

One-Minute Detective is a Flutter-based mobile mystery game where users solve fictional crime cases within 60 seconds. Players analyze suspects, investigate clues, use hints, and identify the culprit. The application includes a timer, scoring system, multiple cases, difficulty levels, and case unlocking. Developed using Flutter and Dart, the app uses local storage to save player progress. The project aims to improve logical thinking, observation, and decision-making skills through an interactive gaming experience.
